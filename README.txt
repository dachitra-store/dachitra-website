DACHITRA - FREE STARTER WEBSITE

WHAT IS INCLUDED
- Responsive, heritage-inspired DACHITRA website
- Home, collection, brand story and contact sections
- WhatsApp enquiry buttons on product cards
- Product catalogue editable in script.js
- Colours, typography and layout editable in style.css

IMPORTANT
This is a free static website starter, not a full WooCommerce store.
It does not include a shopping cart, customer accounts, inventory management,
automated shipping, or integrated online checkout. WhatsApp enquiries work now.
For online payments, you can later add a payment link / payment gateway or move
to WooCommerce. Payment providers may charge transaction fees.

HOW TO EDIT
1. Open index.html to edit text and sections.
2. Open script.js and edit the products array to change product names, prices,
   descriptions and image paths.
3. Put your product photos in the assets folder and set image: "assets/photo.jpg".
4. Open style.css to change colours, fonts, spacing and layout.

HOW TO PREVIEW
Double-click index.html to open it in a browser.

FREE PUBLISHING OPTIONS
You can publish this static site using GitHub Pages or Netlify's free tier.
You will still need to own/connect dachitra.in if you want that custom domain.
Custom-domain use may require domain purchase and DNS configuration.

BEFORE LAUNCH
- Replace all sample product names, prices and descriptions with actual details.
- Add your real logo and product photographs.
- Add accurate shipping, returns, privacy and terms pages.
- Test all WhatsApp links on mobile.
- Configure a secure payment solution before accepting online payments.
